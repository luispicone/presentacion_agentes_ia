# Presentación sobre fundamentos, creación y uso de Agentes de IA

Repositorio de trabajo para una presentación ejecutiva de 20 minutos dirigida a CEOs y directores de empresas argentinas vinculadas a EXCELENCIA / Premio Nacional a la Calidad.

## Estructura

- `docs/contexto-excelencia.md`: contexto institucional relevado sobre EXCELENCIA, FPNC y PNC.
- `presentacion/estructura.md`: estructura principal de la charla, distribución de tiempos y slides sugeridas.
- `presentacion/guion-20-min.md`: guion oral preliminar para exposición de 20 minutos.
- `presentacion/proximos-pasos.md`: tareas siguientes para convertir la estructura en material visual.

## Enfoque

La presentación debe tratar los agentes de IA como una capacidad organizacional vinculada a excelencia en gestión, innovación, procesos, gobernanza y resultados; no como una demostración técnica aislada.
